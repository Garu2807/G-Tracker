# Тестовое задание для стажёра Frontend-направления (весенняя волна 2025)

### Суть задания
Разработать мини-версию системы управления проектами (Project Management Systems).

---

## Инструкция по запуску

### 1. Запуск сервера
1. Убедитесь, что у вас установлен Go (версия 1.20 или выше).
2. Перейдите в папку с серверной частью:
   ```bash
   cd server
   ```
3. Установите зависимости:
   ```bash
   go mod tidy
   ```
4. Запустите сервер:
   ```bash
   go run main.go
   ```

Сервер будет запущен на `http://localhost:8080`.

---

### 2. Установка зависимостей клиента
1. Убедитесь, что у вас установлен Node.js (версия 18 или выше) и пакетный менеджер `npm` или `yarn`.
2. Перейдите в папку с клиентской частью:
   ```bash
   cd client
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```
   или
   ```bash
   yarn install
   ```

---

### 3. Запуск клиента
1. После установки зависимостей запустите клиент:
   ```bash
   npm start
   ```
   или
   ```bash
   yarn start
   ```
2. Клиент будет доступен по адресу `http://localhost:3000`.

---

## Используемый стек технологий

### Backend:
- **Go** — язык программирования для серверной части.
- **Gin** — фреймворк для создания REST API.
- **SQLite** — база данных для хранения данных.

### Frontend:
- **React** — библиотека для создания пользовательских интерфейсов.
- **TypeScript** — язык для типизации.
- **React Router** — библиотека для маршрутизации.
- **React Query** — библиотека для работы с серверными данными.


---
1. **[@hello-pangea/dnd](https://www.npmjs.com/package/@hello-pangea/dnd)** (v18.0.1)
   - Библиотека для реализации drag-and-drop функциональности в React-приложениях.
   - Используется для создания интерактивных интерфейсов с возможностью перетаскивания элементов.

2. **[@tanstack/react-query](https://www.npmjs.com/package/@tanstack/react-query)** (v5.79.0)
   - Библиотека для управления состоянием данных, получаемых из API.
   - Обеспечивает кэширование, синхронизацию и обновление данных в реальном времени.

3. **[Vite](https://vitejs.dev/)** (v6.3.5)
   - Быстрый инструмент для сборки фронтенд-приложений.
   - Поддерживает горячую перезагрузку (HMR) и оптимизацию для разработки и продакшена.

### Примечания
- Убедитесь, что порты `8080` (для сервера) и `3000` (для клиента) свободны.
- Если вы используете прокси-сервер, настройте его для корректной работы с API.
